# 实现代码 Prompt（mss0.16）

本文件只适用于 `code/`。必读清单见 [AGENTS.md](../../AGENTS.md)，规则归属见 [docs/README.md](../README.md)。mss1.5 已归档至 Git 标签 `v1.5-archive`，不作为实现参考。C++ 写法、结构体初始化、算法模块五类结构、工作区与池的契约及文件组织统一见 [style.md](style.md)。

## 可靠性与性能

- 显式异常退出只允许使用项目 [core/assert.h](../../code/core/assert.h) 中的 `assert_(false, "中文错误信息")`；不可达分支不得返回默认对象或其他兜底结果。热路径不增加断言。
- 条件断言只使用 `assert_(条件, "中文错误信息")`；可继续执行的内部告警只使用 `warn_("中文告警信息")`，不能用告警吞掉必须终止的错误。
- 禁止使用标准 `assert`、直接调用 `exit` / `std::exit`（包括 `exit(1)`）、`abort`、`terminate` 或其他终止函数绕过项目诊断，也禁止用异常路径的非零返回码代替上述异常退出。唯一实现例外是 [core/assert.h](../../code/core/assert.h) 对底层终止操作的封装。本限制不影响 `main` 正常结束时的 `return 0` 和普通函数的业务返回（包括向 UI 返回用户输入错误）。
- core/utility 有一系列高性能库，例如位掩码、flat_hashtable 等。引入 map 时，需要优先考虑是否可以规避，若确实无法，则使用哈希表。
- 绝对禁止任何防御性编程，遵循快速失败原则。

## 领域与接口职责

- 引擎 API 直接传实际状态、结果、池和必要工作区，不包一层重复的 DTO；不解析 UI 文本或 HTTP 字段，不反向依赖主 `Config`/主 `Workspace`。
- 直接使用项目已有领域类型和调用入口。不要复制棋盘规则、概率状态、缓存或资源所有权来绕开 API。

## UI、JavaScript、HTML 与 CSS

编辑浏览器代码时先读任务涉及的相邻函数、数据流和 DOM 定义。C++ 转换及文件规则不机械套用到 JS/HTML/CSS。

- 只改本次要求的行为，沿用当前 DOM、请求和状态管理方式。
- 不在浏览器端复制 Game 或引擎已经拥有的规则。如果 Game 尚无相应公开动作 API，不能假装 API 存在，也不能未经批准在浏览器里再写一份规则实现；先指出具体缺口。
- 修改请求字段时同时追踪前端编码、HTTP 接收、Session 解析、领域 API 和响应渲染；不要只凭页面代码推断端到端已完成。
